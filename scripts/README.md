# scripts

Python source for the manuscript's data analysis, figures and tables (accepted version,
November 2026). See the repository root `README.md` for setup and the `vendor/` dependency.

Run scripts from the repository root, e.g. `python scripts/figure_3.py`, unless a
script's own docstring says otherwise. Scripts expect the data referenced in the paper's
Data Availability statement under `Data/` (not included in this repository; see the root
`README.md`). Each script's docstring documents the exact input and output paths it uses.
Figure scripts write to `Data/paper_figures/` and, where noted, also copy their output to
`Manuscript/_drafts/figures/`.

## Shared modules (imported, not run)

| Script | Purpose |
|---|---|
| `forward_model.py` | Beer-Lambert-Bayer forward model: predicts channel absorbance from the illuminant, the Bayer sensitivity and the UV-Vis molar absorptivity, and fits the effective camera path length `l_cam`. Also loads UV-Vis, illuminant and sensitivity data for the other scripts |
| `figstyle.py` | Shared figure style (`figure_style.md`); `save()` refuses figures whose lettering prints below 7 pt |
| `numfmt.py` | Value ± SD formatting: SD to two significant figures, value to the same decimal place |
| `ferroin_scale.py` | Concentration scale for the Fe(II) standards and spikes (iron salt taken as FeSO₄·H₂O, ×1.636) |

## Order of execution

The figure and table scripts read intermediate CSVs written by the analysis scripts. For a
full rebuild from the Zenodo deposit: `uvvis_calibration_figures.py`,
`mb_uvvis_analysis.py`, `native_jpeg_arm.py`, `native_jpeg_metrics.py`,
`recompute_lod_loq_pooled.py`, `bandpass_filter_metrics.py`,
`bandpass_filter_ratio_rows.py`, `channel_common_origin_check.py`,
`ferricyanide_lamp_drift_check.py`, `wine_case_study.py`, then the figure and table
scripts. A single figure script runs on its own once the intermediate CSVs it reads are in
place.

`bandpass_filter_metrics.py` takes the ferricyanide 450/40 ROI from
`rois_ferricyanide_450_40.yaml` in this folder (selected by `roi_selector` on the
29 September filtered set); the methylene blue ROI is selected when the script runs.
